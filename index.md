## 👩🏫 Для кого этот курс?
Этот сайт создан специально для преподавателей, чьи школы перевели на операционную систему **Astra Linux**.

* **Вы учитель и получили новый компьютер?** Начните с урока [«Переезд с Windows»](/lessons/windows-switch) — 5 минут, и станет спокойно.
* **Нужно провести урок уже завтра?** Возьмите готовый [план урока на 40 минут](/lessons/lesson-plan) и [чек-лист кабинета](/lessons/checklists).
* **Что-то сломалось прямо сейчас?** Аварийная таблица в [FAQ](/lessons/faq) и на странице [чек-листов](/lessons/checklists).
* **Не понимаете слово?** Откройте [словарь терминов](/lessons/glossary).

::: tip 📌 Как проходить обучение:
1. Проходите по одному короткому уроку в день (3-5 минут).
2. Повторяйте действия на своем компьютере.
3. Распечатайте шпаргалки (нажмите `Ctrl + P` на странице шпаргалок) и положите их возле компьютера.
4. Переключайте тему оформления (☀️/🌙 в правом верхнем углу) — так, как комфортнее вашим глазам.
:::

## ✨ Как пользоваться сайтом

| Приём | Что даёт |
|---|---|
| `Ctrl + K` (или лупа вверху) | Поиск по всем урокам сразу |
| Правая колонка «На этой странице» | Быстрый прыжок к нужному разделу урока |
| Кнопка ☀️/🌙 | Светлая или тёмная тема — выбор запоминается |
| `Ctrl + P` на любой странице | Печатная версия без меню и лишнего — идеально для шпаргалок |
| «✏️ Предложить правку» внизу урока | Сообщить об ошибке или добавить совет прямо на GitHub |
| Стрелки внизу урока | Последовательный переход «предыдущий → следующий урок» |
