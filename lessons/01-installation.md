🛠️ Модуль 1. Развертывание и установка системы (От «чистого железа» до готового ПК)
Цель модуля: Освоить полный цикл подготовки оборудования, установки ОС Astra Linux и её первичной настройки для передачи в эксплуатацию учителям-предметникам.

::: warning ВНИМАНИЕ: ИНФОРМАЦИЯ ДЛЯ ТЕХНИЧЕСКИХ СПЕЦИАЛИСТОВ Этот раздел предназначен для школьных системных администраторов, лаборантов и учителей информатики, подготавливающих компьютерное оборудование в классах.

Если вы — учитель-предметник и на вашем рабочем компьютере операционная система Astra Linux уже установлена, смело пропускайте данный раздел и переходите к Модулю 2: «Графическая оболочка Fly и организация рабочего пространства». :::


1.1. Подготовка и создание загрузочного накопителя
Качественная подготовка установочного дистрибутива — залог того, что процесс инсталляции пройдет без сбоев и ошибок чтения.
Где официально скачать образ дистрибутива
Скачивание ISO-образов должно производиться строго из официальных и доверенных источников:

Astra Linux Common Edition («Орёл»): Базовая релизная версия общего назначения. Подходит для неприоритетных учебных задач. Скачивается свободно с официального сайта разработчика (ГК «Астра»).
Astra Linux Special Edition («Воронеж» / «Смоленск»): Сертифицированная ФСТЭК операционная система со встроенными средствами защиты информации (СЗИ). Поставляется в образовательные учреждения по государственным контрактам и лицензионным соглашениям.
Проверка целостности ISO-образа (MD5 / SHA256)
::: danger ПОЧЕМУ ЭТО КРИТИЧЕСКИ ВАЖНО? Если в процессе загрузки через интернет файл образа передался с ошибками или не полностью, процесс установки системы оборвется или создаст нестабильно работающую ОС. :::

Перед записью на USB-накопитель обязательно сверьте хэш-сумму скачанного файла с официальным значением на сайте. В ОС Windows это делается через штатную командную строку (cmd):

certutil -hashfile C:\Users\User\Downloads\astralinux.iso MD5

Или для проверки хэша SHA256:

certutil -hashfile C:\Users\User\Downloads\astralinux.iso SHA256

Если полученный хэш-код полностью совпадает с указанным на портале загрузки — образ целостен и готов к записи.
Создание установочной флешки из-под Windows
Для записи образа на USB-накопитель объемом от 8 ГБ используйте одну из следующих программ:

Rufus: Наиболее популярная утилита.
Выберите целевой USB-диск и файл astralinux.iso.
Схема раздела: GPT (для современных ПК с UEFI) или MBR (для устаревших ПК с Legacy BIOS).
Файловая система: FAT32 или NTFS.
BalenaEtcher: Простая кроссплатформенная программа. Процесс состоит из трёх шагов: Flash from file ➔ Select target ➔ Flash!.
Ventoy: Лучшее решение для тех, кто обслуживает много компьютеров. Вы один раз форматируете флешку утилитой Ventoy, а затем просто копируете на неё файлы .iso как обычные документы. При загрузке вы увидите удобное меню выбора образа.


1.2. Настройка BIOS / UEFI и подготовка компьютера
Чтобы компьютер запустил установщик с созданной флешки, нужно скорректировать настройки базовой системы ввода-вывода (BIOS/UEFI).
Вход в BIOS/UEFI
Включите компьютер и сразу нажимайте клавишу входа. В зависимости от производителя материнской платы используйте:

Del или F2 — стационарные ПК (ASUS, Gigabyte, MSI, ASRock).
F12, F10, F8 или Esc — ноутбуки и моноблоки (HP, Lenovo, Acer, Dell).
Отключение режима Secure Boot
::: tip КЛЮЧЕВОЙ ШАГ ПРИ НАСТРОЙКЕ Функция Secure Boot проверяет цифровые подписи загрузчиков. По умолчанию она ориентирована на ключи системы Windows. Для беспрепятственного запуска и работы сторонних драйверов в Linux этот режим необходимо отключить. :::

Зайдите в раздел Security, Boot или Authentication.
Найдите пункт Secure Boot и переведите его значение в Disabled.
Режим загрузки (Boot Mode) для современных ПК переведите в UEFI. Для оборудования старше 10 лет оставьте значение Legacy или CSM.
Выбор устройства загрузки (Boot Menu)
Вы можете переставить USB-накопитель на первое место в списке приоритетов загрузки (Boot Option #1) или при включении компьютера нажать клавишу вызова Boot Menu (обычно F12, F11 или F8) и разово выбрать вашу установочную флешку.

Разметка системного диска (Выбор стратегии)
На этапе «Разметка дисков» мастер предложит несколько вариантов работы с хранилищем:
Вариант А. Автоматическая разметка («Авто — использовать весь диск»)
Идеально подходит для новых ПК или при полной замене ОС. Установщик самостоятельно затрет старые данные и создаст требуемую структуру.
Вариант Б. Ручная разметка (Рекомендуемый стандарт для школ)
Позволяет изолировать пользовательские данные от файлов операционной системы. Если в будущем ОС потребуется переустановить, все методические наработки учителя останутся нетронутыми.

Выбор уровня защищенности (Astra Linux Special Edition)
При установке сертифицированной версии выберите профиль безопасности:

Базовый («Орёл»): Стандартные функции защиты. Подходит для компьютеров в обычных предметных кабинетах.
Усиленный («Воронеж»): Включает контроль целостности и мандатный контекст. Подходит для ПК администрации школы (директор, завучи, бухгалтерия), где обрабатываются персональные данные согласно ФЗ-152.
Максимальный («Смоленск»): Максимальная изоляция процессов. В учебном процессе практически не применяется из-за избыточной строгости ограничений.
Создание учетной записи Администратора
Система попросит ввести имя и пароль первичного пользователя.

Имя пользователя: Вводите строчными латинскими буквами (например, tech_admin или school_operator).
Пароль: Задайте надежную парольную комбинацию. Запомните её — эти данные будут запрашиваться при установке любого нового ПО, принтеров и изменении сетевых настроек через команду sudo.

::: warning ВАЖНО Не используйте имя пользователя admin или administrator — в ряде дистрибутивов Linux данные имена являются зарезервированными служебными логинами. :::
Выбор программного обеспечения
На этапе выбора компонентов отметьте необходимые группы пакетов:

[X] Графический интерфейс Fly — основной рабочий стол системы (обязательно).
[X] Средства работы в сети Интернет — браузеры и сетевые утилиты.
[X] Офисные программы — пакет LibreOffice/МойОфис.
[X] Средства мультимедиа — аудио- и видеоплееры.

Снимите галочки с серверных компонентов (базы данных, веб-сервер), если компьютер настраивается для повседневной работы учителя.

По завершении процесса извлеките флешку и нажмите «Продолжить» для перезагрузки ПК.


1.4. Первичная настройка после установки (Post-Install)
После первой загрузки и входа в систему необходимо выполнить несколько шагов для финализации настройки.
Подключение к сети Интернет
В правом нижнем углу рабочего стола (в трее) найдите иконку утилиты NetworkManager:

Для подключения по кабелю (Ethernet) убедитесь, что значок показывает активное соединение.
Для подключения по Wi-Fi кликните по иконке, выберите школьную беспроводную сеть из списка и введите пароль доступа.
Обновление пакетов и компонентов системы
Убедитесь, что на компьютере установлены актуальные обновления безопасности:
Графический способ:
Пройдите в меню: Пуск (Звезда) ➔ Системные ➔ Обновление системы (Astra Update). Следуйте инструкциям на экране.
Консольный способ (Быстрее):
Откройте эмулятор терминала комбинацией клавиш Ctrl + Alt + T и выполните команду:

sudo apt update && sudo apt upgrade -y

При вводе пароля администратора в терминале символы (звездочки) не отображаются на экране из соображений безопасности. Просто введите пароль и нажмите Enter.
Установка проприетарных драйверов видеокарт
Если на компьютере установлена дискретная видеокарта (NVIDIA или AMD), стандартные свободные драйверы могут создавать шлейфы или «подтормаживания» при выводе видео и тяжелых презентаций на проектор.

Для установки фирменного драйвера NVIDIA открывается терминал и выполняется установка соответствующего пакета:

sudo apt update

sudo apt install nvidia-driver

После завершения установки перезагрузите компьютер командой sudo reboot.


📋 Чек-лист готовности компьютера к сдаче учителю
Перед тем как передать настроенный ПК в рабочий кабинет, проверьте выполнение следующих пунктов:

Отключен режим Secure Boot в BIOS/UEFI.
Диск разбит на два основных раздела: системный / и пользовательский /home.
Создана учетная запись администратора с надежным паролем.
Компьютер успешно подключается к сети Интернет (Ethernet / Wi-Fi).
Установлены последние обновления системы.
Графический интерфейс работает плавно, без задержек при разворачивании окон.
