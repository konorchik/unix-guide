# 💾 4.3. Резервные копии и восстановление

**Цель урока:** настроить простую систему страховки для рабочих документов, чтобы потеря файла или поломка компьютера не означала потерю четверти работы.

## Правило 3-2-1 (по-учительски)

* **3** копии важных документов;
* на **2** разных носителях (компьютер + флешка/внешний диск);
* **1** копия — «вне компьютера» (облако школы / второй физический носитель в другом кабинете).

Минимальный рабочий вариант для учителя:

```text
Оригинал:      Документы/Уроки/        (на компьютере)
Копия №1:      флешка «Рабочая»         (в портфеле)
Копия №2:      сетевая папка школы     (если есть — уточните у администратора)
```

::: tip ЧТО КОПИРОВАТЬ ОБЯЗАТЕЛЬНО
Только папку `Документы` (плюс `Рабочий стол`, если там что-то лежит). Копируйте целиком раз в неделю — это 5 минут. Программы и настройки переустанавливаются, ваши файлы — нет.
:::

## Ручная копия на флешку (за 1 минуту)

1. Подключите флешку (урок [1.2](/lessons/files)).
2. В файловом менеджере выделите папку `Документы` ➔ `Ctrl + C`.
3. Откройте флешку ➔ `Ctrl + V`. Дождитесь окончания копирования.
4. **Безопасно извлеките** флешку.

### Автоматизация через терминал (для продвинутых)

Раз в неделю можно обновлять копию одной командой (`rsync` докопирует только изменившиеся файлы):

```bash
rsync -av ~/Документы/ /media/$USER/FLASHKA/backup/
```

Файлы с пробелами и кириллицей работают корректно; имя тома флешки (`FLASHKA`) посмотрите в `/media/ваш_логин/`.

## Облако и сетевые папки школы

Если школа использует корпоративное облако/сетевые диски:

* держайте папку `Уроки` **симлинком или клиентом синхронизации** внутри облачной папки;
* не загружайте персональные данные учеников в публичные облака (Яндекс.Диск личного аккаунта, Google Drive) — это требование ФЗ-152; используйте только согласованные школьные сервисы.

## Восстановление случайно удалённого файла

**Шаг 1. Корзина.** Двойной клик по значку «Корзина» на рабочем столе ➔ найдите файл ➔ правая кнопка ➔ **«Восстановить»** (вернётся на прежнее место).

**Шаг 2. Автосохранение LibreOffice.** Файл не сохраняли вообще? Откройте программу заново: она предложит восстановить несохранённые документы. Также проверьте: Сервис ➔ Параметры ➔ Пути ➔ «Резервные копии» и папку `~/.config/libreoffice/4/user/backup`.

**Шаг 3. Версия файла.** Если документ открывался несколько раз, в LibreOffice есть **Файл ➔ Восстановить ➔ Версии…** — можно откатиться к более раннему состоянию документа.

::: danger ЕСЛИ ФАЙЛ ПРОПАЛ С ФЛЕШКИ
Не записывайте на неё ничего! Чем больше новых данных, тем меньше шанс восстановить старые. Скажите администратору — иногда помогают утилиты восстановления (TestDisk/PhotoRec), но они требуют прав и аккуратности.
:::

## Перед передачей компьютера в ремонт / сдачей техники

1. Скопируйте рабочие документы на съёмный носитель.
2. Очистите корзину и временные файлы («Пуск» ➔ «Очистка» или вручную).
3. Не храните пароли в браузере на сдаваемом компьютере — выйдите из профилей.
4. Передачу оформите актом через завхоза/администратора.

## 📚 Официально и для опытных

Коротко — что говорят документы «Астра Линукс» и где копать глубже, если вы уже работаете в системе уверенно:

* Штатные инструменты резервного копирования: `rsync`, архиватор `tar`, графический **Deja Dup** доступен из репозитория; в SE дополнительно применяются мандатно-совместимые схемы хранения бэкапов (вики «Резервное копирование»).
* Загрузочный Live-USB с тем же ISO, что установлен в школе, позволяет восстановить систему без потери данных пользователей (официальная инструкция — в руководстве пользователя SE).

::: tip Как пользоваться этими ссылками
Официальная вики **wiki.astralinux.ru** и портал документации **docs.astralinux.ru** доступны без регистрации; страницы с пометкой «Special Edition» описывают сертифицированную ФСТЭК редакцию, которая стоит в большинстве школ. Если раздел вики недоступен — скачайте официальное руководство в PDF с docs.astralinux.ru.
:::

## Практическое задание ✅

1. Заведите флешку «Рабочая» и скопируйте на неё всю папку `Документы`.
2. Случайно удалите тестовый файл и восстановите его из корзины.
3. Найдите в LibreOffice диалог «Восстановить ➔ Версии» для своего конспекта.
4. Спросите администратора, есть ли в школе сетевой диск/облако для учителей и как туда подключаться.
