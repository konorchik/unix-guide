# 📊 2.2. Таблицы Calc и диаграммы

**Цель урока:** сделать в LibreOffice Calc рабочий файл учителя — журнал оценок с автоматическим подсчётом среднего балла и диаграмму для отчётности.

## Интерфейс: ячейки, строки, столбцы

* **Столбцы** обозначаются буквами (A, B, C…), **строки** — номерами (1, 2, 3…).
* Адрес ячейки — как бой в «морском бою»: `B7` — столбец B, строка 7.
* Введите значение и нажмите `Enter`; `Tab` — переход вправо; двойной клик по ячейке — редактирование.

::: tip АНАЛОГИЯ С EXCEL
Calc повторяет Excel почти один-в-один: те же адреса, похожие функции, только разделители аргументов в русскоязычной версии — точка с запятой `;`, а не запятая.
:::

## Первый лист: журнал оценок

Введём таблицу: фамилии и пять оценок, затем автоматом посчитаем средний балл.

| | A | B | C | D | E | F | G |
| --- | --- | --- | --- | --- | --- | --- | --- |
| **1** | Ученик | Пр.1 | Пр.2 | Пр.3 | КР | Итог |
| **2** | Иванов А. | 4 | 5 | 5 | 4 | `=СРЗНАЧ(B2:E2)` |

### Формулы учителя

Все формулы начинаются со знака `=`. Самый нужный набор:

| Функция | Пример | Что делает |
| --- | --- | --- |
| `СУММ` | `=СУММ(B2:B30)` | Сумма диапазона (часы нагрузки, баллы) |
| `СРЗНАЧ` | `=СРЗНАЧ(B2:E2)` | Среднее арифметическое (средний балл) |
| `МАКС` / `МИН` | `=МАКС(B2:B34)` | Лучший / худший результат |
| `СЧЁТ` | `=СЧЁТ(B2:B34)` | Сколько числовых значений (сколько сдали) |
| `ЕСЛИ` | `=ЕСЛИ(F2>=3;"Удовлетворительно";"Не аттестован")` | Проверка условия |

### Как скопировать формулу вниз

1. Посчитайте средний балл для первой строки: выделите `G2`, введите `=СРЗНАЧ(B2:E2)`, `Enter`.
2. Наведите курсор на **правый нижний угол** ячейки (чёрный крестик) и протяните вниз до конца списка — формула сама «сдвинется» для каждой строки.

::: warning ОШИБКА «#ДЕЛ/НА_НОЛЬ»
Значит, в диапазоне нет ни одной оценки (все клетки пустые). Это нормально для отсутствовавшего ученика — можно скрыть ошибку формулой `=ЕСЛИОШИБКА(СРЗНАЧ(B2:E2);"—")`.
:::

### Закрепление шапки таблицы

Чтобы при прокрутке вниз оставалась видимой строка с названиями: **Вид ➔ Закрепить окна** (при установленном курсоре в ячейке `A2`).

## Условное форматирование: подсветка троек и двоек

1. Выделите диапазон оценок (`B2:E34`).
2. **Формат ➔ Условное ➔ Условие…**
3. Создайте правила:
   * «Значение ячейки » ➔ `меньше или равно` ➔ `2` ➔ стиль **красный фон**;
   * `равно` ➔ `3` ➔ **жёлтый фон**;
   * `больше или равно` ➔ `4` ➔ **зелёный фон**.

Теперь «проблемные» ученики видны мгновенно — удобно на родительском собрании.

## Диаграмма для отчёта за четверть

1. Выделите два столбца: фамилии (`A2:A12`) и итоговые средние баллы (`G2:G12`) — выделяйте с зажатым `Ctrl`.
2. **Вставка ➔ Диаграмма…**
3. Тип: **Столбчатая** ➔ Далее ➔ уберите галку «Легенда» (она не нужна для одного ряда) ➔ Добавьте заголовки: «Средний балл класса».
4. Готовую диаграмму можно копировать в Impress или Writer как картинку: правая кнопка по диаграмме ➔ «Копировать» ➔ вставить в презентацию.

::: tip ДЛЯ ПРОЕКТОРА
Делайте шрифт подписей на диаграмме не меньше 18 pt и включите «показать значения данных» — с задней парты видно точные цифры.
:::

## Печать и сохранение

* Перед печатью проверьте область: **Формат ➔ Область печати ➔ Определить**.
* Широкие таблицы печатайте альбомной ориентацией: Файл ➔ Параметры страницы ➔ Ориентация «Альбомная», вкладка «Таблица» ➔ «Вписать в… 1 страницу по ширине».
* Сохраняйте для Windows в **.xlsx**: Файл ➔ Сохранить как ➔ тип «Excel 97–2003/365 (.xlsx)» (см. правило из урока [2.1](/lessons/office)).

## Практическое задание ✅

1. Создайте журнал на 10 учеников и 4 проверки, посчитайте средний балл через `СРЗНАЧ`.
2. Скопируйте формулу вниз на весь список.
3. Подсветите двойки красным через условное форматирование.
4. Постройте столбчатую диаграмму средних баллов и сохраните файл в `.xlsx`.
