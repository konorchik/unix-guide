# ✅ Чек-листы: распечатайте и положите на учительский стол

Все чек-листы рассчитаны на печать одной кнопкой (`Ctrl + P`) — сайт автоматически скроет лишнее и оставит только список.

::: warning ПРАВИЛО ОДНОЙ СТРАНИЦЫ
Каждый блок ниже печатайте на отдельном листе A5/A4 и ламинируйте — они живут рядом с клавиатурой учителя.
:::

## 🌅 Утренний чек-лист кабинета (10 минут до звонка)

* [ ] Включён главный выключатель/пилот класса, питание ПК подано
* [ ] Проектор включён и показывает картинку с учительского ПК (Super+P → «Дублировать»)
* [ ] Учительский ПК загрузился, вход выполнен, интернет открывается ([проверка](/lessons/internet))
* [ ] Флешка с раздаточными материалами подключена и **безопасно извлекается** потом
* [ ] Принтер включён, бумага есть, тестовая страница печатается ([подключение](/lessons/peripherals))
* [ ] Колонки/микрофон дают звук (если нужен на уроке)
* [ ] Открыта вкладка нужного урока на этом сайте
* [ ] Журнал/таблица Calc готовы к оценкам

## ▶️ Начало урока (2 минуты)

* [ ] Дети вошли под своими учётными записями ([учётные записи](/lessons/accounts))
* [ ] Правила за ПК озвучены: не трогать чужие файлы, не выдёргивать флешки
* [ ] Цель урока показана на проекторе (скопируйте из [плана урока](/lessons/lesson-plan))
* [ ] Раздаточные файлы скопированы детям в домашние папки

## 🔚 Конец урока (3 минуты)

* [ ] Работы сохранены: «Файл → Сохранить как → .docx» ([офис](/lessons/office))
* [ ] Флешки безопасно извлечены (правый клик → «Извлечь устройство»)
* [ ] Резервная копия лучших работ — в папку «Резерв» ([бэкап](/lessons/backup))
* [ ] Дети вышли из системы («Завершение сеанса»), а не просто закрыли окна
* [ ] Проектор и выключатель питания — выключить
* [ ] Замечания по технике записаны в журнал администратора

## 🆘 Аварийный чек-лист (что делать прямо сейчас)

| Ситуация | Первые 3 действия | Подробно |
|---|---|---|
| ПК не включается | 1) питание в розетке 2) кабель монитора 3) зовите администратора | [урок 0](/lessons/01-installation) |
| Завис одно окно | Esc → подождать 30 сек → правый клик панели задач → «Закрыть окно» | [сбои](/lessons/security) |
| Пропал интернет | 1) значок сети 2) другой браузер 3) переподключить кабель | [интернет](/lessons/internet) |
| Не печатает | 1) документ в очереди? 2) бумага/замятие 3) «Перезапустить принтер» | [принтеры](/lessons/peripherals) |
| Потерян файл | 1) Корзина 2) поиск по имени 3) резервная копия | [бэкап](/lessons/backup) |
| Забыт детский пароль | Только администратор: сброс учётной записи | [аккаунты](/lessons/accounts) |

## 🧹 Генеральная уборка компьютера (раз в четверть, вместе с администратором)

* [ ] Обновления системы установлены ([терминал/центр приложений](/lessons/terminal))
* [ ] Лишние детские профили удалены
* [ ] Очистка кэша браузера
* [ ] Проверка свободного места на диске
* [ ] Антивирус обновлён и просканировал съёмные носители ([безопасность](/lessons/security))
* [ ] Резервные копии всех рабочих папок учителя — на внешнем диске

---

💡 **Совет:** распечатайте «Аварийный чек-лист» и повесьте на внутреннюю дверцу учительского стола — в стрессовой ситуации он снимает 90% вопросов.

## 📚 Официально и для опытных

Коротко — что говорят документы «Астра Линукс» и где копать глубже, если вы уже работаете в системе уверенно:

* Пункты чек-листов опираются на рекомендации «Астра Линукс» по подготовке рабочих мест (руководство пользователя SE) и типовые регламенты эксплуатации образовательных ИТ-сред.

::: tip Как пользоваться этими ссылками
Официальная вики **wiki.astralinux.ru** и портал документации **docs.astralinux.ru** доступны без регистрации; страницы с пометкой «Special Edition» описывают сертифицированную ФСТЭК редакцию, которая стоит в большинстве школ. Если раздел вики недоступен — скачайте официальное руководство в PDF с docs.astralinux.ru.
:::
