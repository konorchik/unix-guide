# 🧰 Справочник команд терминала

**Для кого:** для тех, кто уже не боится «чёрного окна» и хочет работать быстрее. Каждая команда — с переводом на человеческий. Все команды штатные для Astra Linux SE (проверяйте по официальному руководству администратора на docs.astralinux.ru).

## Файлы и папки

| Команда | Что делает | Пример |
| --- | --- | --- |
| `ls -la` | показать содержимое папки, включая скрытые | `ls -la ~/Документы` |
| `cd путь` | перейти в папку | `cd ~/Документы/Уроки` |
| `pwd` | «где я?» — показать текущую папку | `pwd` |
| `cp файл куда` | скопировать | `cp конспект.docx ~/Desktop` |
| `mv файл новая_папка` | переместить/переименовать | `mv черновик.docx итог.docx` |
| `mkdir имя` | создать папку | `mkdir 2026-09-класс5` |
| `find ~ -name "*.pdf"` | найти файлы по имени | `find ~ -name "*.pdf"` |
| `du -sh ~/Документы` | сколько места занимает папка | `du -sh ~/Документы` |

## Диски и флешки

| Команда | Что делает |
| --- | --- |
| `df -h` | свободное место на всех дисках (человеческие Гб) |
| `lsblk` | список всех накопителей и разделов — видно вашу флешку (`sdb1`) |
| `mount | grep media` | куда что примонтировано |
| `udisksctl unmount -b /dev/sdb1` | безопасно извлечь флешку из терминала |

## Пакеты (установка программ)

| Команда | Что делает |
| --- | --- |
| `apt search vlc` | найти программу в репозитории |
| `apt show vlc` | описание пакета: версия, размер, домашняя страница |
| `sudo apt update` | обновить список доступных пакетов |
| `sudo apt install vlc` | установить программу |
| `dpkg -l \| less` | список установленных программ (стрелки — листать, `q` — выйти) |

::: warning Права администратора
Команды с `sudo` требуют пароль администратора и меняют систему. В школьной среде их выполняет или согласует системный администратор — это требование политики ИБ.
:::

## Печать

| Команда | Что делает |
| --- | --- |
| `lpstat -p` | какие принтеры подключены и включены |
| `lpstat -t` | очередь печати — где «застрял» ваш документ |
| `lpr раздатка.pdf` | отправить файл на печать |
| `cancel <номер_задания>` | отменить задание из очереди |

## Сеть и проверка связи

| Команда | Что делает |
| --- | --- |
| `ip a` | адреса компьютера (ищетесь Wi-Fi/WLAN) |
| `nmcli device status` | состояние сетевых подключений |
| `ping -c 4 astralinux.ru` | есть ли интернет (4 проверки) |
| `curl -I https://edu.ru` | отвечает ли сайт (без скачивания страницы) |

## Диагностика «что не так с компьютером»

| Команда | Что делает |
| --- | --- |
| `astra_version` / `cat /etc/astra_version` | версия Astra Linux |
| `uname -a` | ядро и архитектура |
| `free -h` | сколько памяти свободно |
| `top` (или `htop`) | какие программы «съедают» процессор; `q` — выйти |
| `journalctl -xe -n 50` | последние 50 строк системного журнала — покажите администратору |

::: tip Как пользоваться справочником
Скопируйте команду ➔ вставьте в терминал (`Ctrl+Shift+V`) ➔ нажмите Enter. Команды из таблиц выше **ничего не удаляют и не ломают** — их можно выполнять смело. Не выполняйте то, чего нет в этом списке и официальных руководствах docs.astralinux.ru.
:::

## Практическое задание ✅

1. Узнайте версию системы и свободного места: `cat /etc/astra_version`, `df -h`.
2. Найдите все PDF в домашней папке: `find ~ -name "*.pdf"`.
3. Посмотрите очередь печати: `lpstat -t`.
