# ❓ Частые вопросы (FAQ)

Собрано из реальных вопросов коллег при переходе на Astra Linux. Если вашего вопроса нет — напишите администратору школы, а мы добавим ответ сюда.

## Общие

**А мои файлы из Windows куда денутся?**
Никуда. Старый диск можно подключить как второй или скопировать папки `Мои документы`/`Рабочий стол` на флешку до переустановки. После установки сложите их в свою домашнюю папку (`Документы`, `Изображения`…). Порядок действий — урок [1.2](/lessons/files).

**Я привык к Windows, сколько учить заново?**
Интерфейс почти идентичен (см. [1.0. Переезд с Windows](/lessons/windows-switch)). Обычно хватает недели ежедневной работы.

**На телефоне/планшете будет работать?**
Astra Linux — система для компьютеров и ноутбуков. Для мобильных устройств используйте школьные веб-сервисы через браузер.

**Вирусы? Нужен ли антивирус?**
Для Windows-вирусов Astra невосприимчива. Опасность — фишинг и вредоносные документы. Соблюдайте правила гигиены из урока [4.1](/lessons/security); сканер для флешек учеников настроит администратор.

## Файлы и носители

**Флешка из-под «двойки» не открывается / пишет «нет прав»**
Чаще всего дело в файловой системе NTFS/exFAT или «грязном» состоянии после небезопасного извлечения. Попробуйте другой USB-порт; если не помогло — отформатируйте флешку в **FAT32/exFAT** (все данные сотрутся!) через «Параметры» ➔ «Диски» или попросите администратора. Профилактика — безопасное извлечение, урок [1.2](/lessons/files).

**Как открыть файл, который «неизвестного типа»?**
Правая кнопка по файлу ➔ «Открыть в…» ➔ выбрать программу (для PDF — просмотрщик документов, для .docx — LibreOffice Writer). Галочка «Запомнить» сделает программу стандартной для этого типа.

**Где печать и как сделать двустороннюю?**
`Ctrl + P` в любой программе. Двусторонняя печать доступна, если принтер её поддерживает: в диалоге печати выберите вкладку свойств принтера ➔ «Двусторонняя». Подробно — [3.1](/lessons/peripherals).

## Программы и сервисы

**Чем открыть 1С / «Электронный журнал» / региональные порталы?**
Большинство школьных систем работают **через браузер** (Chromium/Firefox). Специализированные десктопные приложения (1С) имеют Linux-версии — уточните у администратора, какая версия стоит в школе.

**Как зайти на Госуслуги / подтвердить учётную запись с компьютера на Astra?**
Через браузер; при установке сертификатов/криптопровайдеров (КриптоПро CSP есть версия для Linux) потребуется помощь администратора и права. Не скачайте «средства для ГОСТ» с сомнительных сайтов.

**Можно ли поставить Windows рядом (второй системой)?**
Технически да, но в школьной инфраструктуре обычно запрещено требованиями ИБ. Любые изменения разделов диска делает только администратор.

**Не открывается сайт школы / «соединение сброшено»**
Проверьте дату и время в трее (расхождение сбивает сертификаты), затем попробуйте другой браузер. Если проблема только с одним сайтом — обратитесь к администратору сети.

## Электронная подпись и документы

**Нужна ЭЦП для приказов — что делать?**
Установка токена (Рутокен/Jacarta) и криптопрограмм требует прав администратора и плагинов браузера. Запишите модель токена и обратитесь к администратору — типовая процедура занимает 15 минут.

::: tip КАК ПОЛУЧИТЬ ОТВЕТ БЫСТРО
Сфотографируйте экран с ошибкой, опишите: что делали ➔ что получилось ➔ какой текст ошибки. С такой информацией администратор решит вопрос в разы быстрее. Экстренная памятка — в разделе [Шпаргалки](/lessons/shortcuts).
:::
