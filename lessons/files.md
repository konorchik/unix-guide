# 📁 1.2. Работа с файлами и флешками

**Цель урока:** уверенно находить свои файлы, создавать папки и безопасно работать с USB-накопителями.

## Файловый менеджер

Главный инструмент работы с файлами в Astra Linux — файловый менеджер **«Файлы» (fly-fm)**. Откройте его значком папки на панели задач или двойным кликом по «Домашней папке» на рабочем столе.

Структура вашей **домашней папки** (`/home/ваше_имя`):

| Папка | Для чего использовать |
| --- | --- |
| Рабочий стол | Файлы, которые нужны «на виду» |
| Документы | Конспекты уроков, планы, приказы |
| Загрузки | Всё, что скачали из интернета — периодически разбирайте |
| Изображения | Фото для презентаций |
| Музыка, Видео | Мультимедиа для уроков |

::: tip ГЛАВНОЕ ПРАВИЛО
Все важные файлы храните **внутри домашней папки**, а не на системном диске. Только они гарантированно сохраняются при переустановке системы.
:::

## Основные операции

* **Копировать / вставить:** `Ctrl + C` / `Ctrl + V` (как в Windows).
* **Вырезать / вставить:** `Ctrl + X` / `Ctrl + V`.
* **Переименовать:** выделить файл и нажать `F2`.
* **Удалить в корзину:** клавиша `Delete`, восстановить — из корзины на рабочем столе.
* **Поиск:** в окне файлового менеджера нажмите `Ctrl + F` и начните печатать имя файла.
* **Создать папку:** правая кнопка мыши по пустому месту ➔ «Создать» ➔ «Папку».

## Как назвать файл, чтобы он не потерялся

Школьные документы живут годами и переходят между компьютерами. Правила надёжных имён:

1. **Дата вперёд**: `2026-10-31_KTP_5klass.docx` — файлы автоматически сортируются по порядку.
2. **Без пробелов и спецсимволов** (`/ \ : * ? " < > |`) — используйте `_` или `-`; пробелы ломают ссылки в некоторых программах.
3. **Понятное расширение**: `.docx`, `.xlsx`, `.pptx`, `.pdf` — система сама выберет программу для открытия.
4. Не называйте файлы «документ1», «новая папка (2)» — через месяц вы не найдёте нужное.

::: tip АРХИВЫ (ZIP/RAR)
Правая кнопка по файлу ➔ **«Сесть в архив…»** — так удобно передавать коллегам пачку файлов одной ссылкой. Архивы с паролем от учеников не открываются без программы `p7zip` — попросите администратора установить её один раз на кабинетный ПК.
:::

## Быстрый доступ к любимым папкам

В левом столбце файлового менеджера есть «Закладки»: выделите часто используемую папку (`Документы/Уроки`) ➔ меню **Заккладки ➔ Добавить закладку** (`Ctrl + D`). Теперь нужный путь — один клик.

## Подключение флешки

1. Вставьте USB-накопитель в порт.
2. Через несколько секунд в правом нижнем углу появится **уведомление** — кликните по нему, чтобы открыть флешку.
3. Также флешка появляется в левой колонке файлового менеджера в разделе **«Устройства»**.

::: danger КАК ПРАВИЛЬНО ИЗВЛЕКАТЬ ФЛЕШКУ
Просто выдернуть накопитель — риск потерять данные! Сначала:
1. Закройте все окна и программы, работающие с файлами флешки.
2. В файловом менеджере нажмите на значок **⏏ (Извлечь)** рядом с названием флешки или правой кнопкой ➔ **«Безопасно извлечь»**.
3. Дождитесь уведомления «Можно извлекать устройство» — только потом вынимайте.
:::

## Флешка не открывается?

Частые причины и решения:

* **Флешка в формате NTFS (из-под Windows):** обычно открывается сразу. Если нет — перетестируйте на другом порту (желательно сзади системного блока — там порты надёжнее).
* **Накопитель «виден, но пустой»:** возможно, на нём есть скрытые разделы. Попросите администратора школы проверить его через «Управление дисками».
* **Вирусная флешка:** если после подключения система ругается на ошибки чтения, отключите флешку и проверьте её антивирусом на другом компьютере.

## Практическое задание ✅

1. Создайте в папке «Документы» структуру: `Уроки` → внутри папки по числу своих предметов.
2. Скопируйте любой файл в свою папку и переименуйте его через `F2`.
3. Подключите флешку, скопируйте на неё один файл и **безопасно извлеките** её.
