# 📖 Словарь: что значит то, о чём говорят в уроках

**Цель:** ни один термин на этом сайте не должен вас остановить. Открывайте словарь во время чтения урока.

::: tip КАК ИСКАТЬ БЫСТРО
Нажмите `Ctrl + F` в браузере и наберите слово — страница сама подсветит нужную строку словаря.
:::

## А–З

| Термин | Простыми словами |
|---|---|
| **Astra Linux** | Российская операционная система (как Windows), сделанная для госучреждений и школ. Есть версии «Орёл» (общая), «Воронеж» (защита) и спецвыпуск |
| **Браузер** | Программа для выхода в интернет (Firefox, Яндекс.Браузер). Как «окно» в сеть |
| **Буфер обмена** | Временное хранилище для скопированного: Ctrl+C кладёт туда, Ctrl+V берёт обратно |
| **Версия системы** | Например «1.7» или «1.8» — как «поколение» Astra. Проверить: меню «Пуск → О системе» |
| **Горячая клавиша** | Сочетание клавиш вместо мышкой: Alt+F4 — закрыть окно |
| **Дистрибутив** | «Сборка» Linux: система + программы + настройки в одном установщике. Astra — один из дистрибутивов |
| **Жёсткий диск** | Внутрикомпьютерное хранилище файлов. Обозначается как большой раздел, флешки видны отдельно |
| **Зависание** | Программа перестала отвечать. Не перезагружайте весь ПК сразу — см. урок про сбои |

## К–П

| Термин | Простыми словами |
|---|---|
| **Каталог** | То же, что «папка». В терминале: `/home/teacher` — домашняя папка учителя |
| **Компиляция** | Превращение текста программы в рабочую. Учителю не нужна — просто устанавливайте готовые пакеты |
| **Локальная сеть** | Сеть внутри школы: общие принтеры, файлы, вход по единому аккаунту |
| **Монитор (экран)** | Дисплей. В настройках Fly можно изменить яркость и разрешение |
| **Оболочка Fly** | Графическая «обёртка» Astra Linux с меню «Пуск» и панелью задач — похожа на Windows |
| **Огнестойкий экран / firewall** | Встроенный «часовой», который не пускает в компьютер посторонних из сети |
| **Пакет (.deb)** | Файл-коробочка с программой. Установка двойным щелчком или через «Центр приложений» |
| **Пароль суперпользователя (root)** | Главный пароль администратора системы. Учителю обычно не нужен — работайте под своей учётной записью |
| **Переименование** | Смена имени файла: правый клик → «Переименовать» (F2) |
| **Подключение (монтирование) флешки** | Система «распознаёт» USB-накопитель и показывает его значок на рабочем столе |
| **Проектор** | Внешний экран урока. Подключается кабелем HDMI/VGA, переключение — Super+P |
| **Раздел диска** | Крупный «отсек» жёсткого диска. Школа часто делает отдельный раздел для данных учеников |

## Р–Я

| Термин | Простыми словами |
|---|---|
| **Раскладка клавиатуры** | Русский/английский язык ввода. Переключение — Alt+Shift или Win+Space |
| **Резервная копия (бэкап)** | Запасная папка «Документы_резерв» на флешке или диске. Делается раз в неделю |
| **Рабочий стол** | Экран со значками после входа в систему — аналог рабочего стола Windows |
| **Сервер** | Компьютер в школе, где лежат общие файлы и учётные записи. Вы к нему подключаетесь, но не настраиваете |
| **Сессия** | Время вашей работы за компьютером от входа до выхода |
| **Система печати (CUPS)** | Программный «диспетчер» принтеров: очередь документов, драйверы |
| **Терминал (консоль)** | Чёрное окошко для команд. Нужен редко — основные команды есть в уроке про терминал |
| **Учётная запись** | Ваш личный вход в систему: имя + пароль. У каждого ученика своя |
| **Файловый менеджер** | Программа для папок и файлов (в Fly — «Файлы»), как «Проводник» в Windows |
| **Формат .docx / .odt** | .docx — формат Word, .odt — формат LibreOffice Writer. Для сдачи работ используйте .docx |
| **Хвосты (dependencies)** | Дополнительные программы, без которых основная не работает. Центр приложений ставит их сам |
| **Центр приложений** | Магазин программ внутри Astra — как «Microsoft Store»: нашёл, нажал «Установить» |
| **Чат/мессенджер** | Программа общения. В школе обычно используется только на ПК учителя |
| **Шлюз (gateway)** | Точка выхода школы в интернет — обычно роутер у администратора |
| **.exe файл** | Программа для Windows. На Astra она НЕ запустится двойным щелчком — ищите аналог в Центре приложений |
| **Эмулятор / Wine** | Способ запустить Windows-программы на Linux. В школьном курсе не используется |
| **Ядро (kernel)** | «Двигатель» операционной системы, скрыт от пользователя. Обновляет администратор |
