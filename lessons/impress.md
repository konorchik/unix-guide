# 📽️ 2.3. Impress: показываем материал классу

**Цель урока:** научиться делать презентации, которые хорошо видно с последней парты, и показывать их на уроке без нервов.

## Правило «с задней парты»

Презентация для класса отличается от документа:

* **1 слайд = 1 мысль.** Не больше 5–6 строк текста.
* Заголовки — **от 32 pt**, текст — **от 24 pt**. Мелкий шрифт на проекторе превращается в кашу.
* Контраст: тёмный текст на светлом фоне (или наоборот). Избегайте жёлтого на белом и серого на чёрном.
* Картинки крупные, без случайных водяных знаков.

## Быстрый старт: шаблон и мастер

1. «Пуск» ➔ **LibreOffice Impress**.
2. При запуске можно выбрать готовый **шаблон** (Меню Файл ➔ Мастер ➔ Презентация) — там есть строгие и «школьные» варианты оформления.
3. Структура слайда: заголовок + содержимое. Новые слайды: `Ctrl + M`.

### Режимы работы со слайдами

* **Обычный** — редактирование одного слайда.
* **Структура** (левая вкладка) — вводите весь текст презентации списком, слайды создаются сами. Самый быстрый способ перенести конспект в презентацию!
* **Сортировщик** — все слайды как картинки: удобно менять порядок перетаскиванием.

## Текст, списки, картинки

* Выделение жирным — `Ctrl + B`, курсив — `Ctrl + I`.
* Маркированный список — кнопка «Список» на панели форматирования; новый пункт списка — `Enter`.
* Картинка: **Вставка ➔ Изображение…** (лучше заранее положить фото в папку `Изображения/Уроки`).
* Рамка вокруг важного: Вставка ➔ Прямоугольник ➔ без заливки, толстая красная обводка.

::: tip АНИМАЦИЯ НЕ НУЖНА
«Вылет текста под музыку» снижает внимание к содержанию. Максимум — простая «Появляемость» по пунктам списка, чтобы показать вопрос ➔ потом ответ.
:::

## Заметки докладчика

Внизу окна есть поле **«Заметки»** — то, что видите только вы:

1. Напишите там план ответа, вопросы классу, номер страницы учебника.
2. При показе включите **двухэкранный режим**: Вид ➔ Консоль докладчика (или при подключении проектора выберите режим «Расширить» из урока [3.1](/lessons/peripherals)).
3. На экране учеников — слайд, у вас на ноутбуке — слайд + заметки + таймер.

## Показ на уроке

| Клавиша | Действие |
| --- | --- |
| `F5` | Начать показ с первого слайда |
| `Shift + F5` | Начать с текущего слайда |
| `→ / Пробел / Enter / клик мышью` | Следующий слайд |
| `←` | Предыдущий слайд |
| `Home / End` | Первый / последний слайд |
| `B` / `W` | Чёрный / белый экран (пауза внимания, например при шуме в классе) |
| `Esc` | Выйти из показа |
| `NumPad + / -` | Увеличить / уменьшить текущий слайд (зум для схемы) |

::: warning ПРОВЕРЬТЕ ДО ЗВОНКА
Откройте презентацию и запустите показ на том компьютере и проекторе, где будет урок. Шрифты, которых нет в системе, заменятся, и вёрстка «поедет». Идеально — держать копию `.pptx` на флешке и экспорт в PDF.
:::

## Сохранение и обмен

* Для коллег с Windows: **Файл ➔ Сохранить как ➔ PowerPoint (.pptx)** (правило совместимости — в уроке [2.1](/lessons/office)).
* Раздаточный материал: **Файл ➔ Экспорт в PDF** ➔ «Документ» или «6 слайдов на лист» — компактные копии для родителей/коллегии.
* Автосохранение резервных копий включено по умолчанию; проверьте Сервис ➔ Параметры ➔ Открыть/Сохранить.

## 📚 Официально и для опытных

Коротко — что говорят документы «Астра Линукс» и где копать глубже, если вы уже работаете в системе уверенно:

* Режим докладчика и показ по второму экрану опираются на раскладку дисплеев Xrandr; управление — `Super+P` (Fly Display), подробно в вики-разделе «Подключение внешнего монитора/проектора».

::: tip Как пользоваться этими ссылками
Официальная вики **wiki.astralinux.ru** и портал документации **docs.astralinux.ru** доступны без регистрации; страницы с пометкой «Special Edition» описывают сертифицированную ФСТЭК редакцию, которая стоит в большинстве школ. Если раздел вики недоступен — скачайте официальное руководство в PDF с docs.astralinux.ru.
:::

## Практическое задание ✅

1. Перенесите план своего ближайшего урока в Impress через режим «Структуры».
2. Сделайте заголовки 32 pt, текст 24 pt, добавьте одну крупную иллюстрацию.
3. Напишите заметки докладчика на двух слайдах.
4. Сохраните файл в `.pptx` и экспортируйте раздачу «6 слайдов на страницу» в PDF.
