# 🌐 1.4. Интернет и браузер

**Цель урока:** подключиться к интернету в кабинете и настроить браузер так, чтобы на уроке всё открывалось с первого клика.

## Проверка подключения

Значок сети находится в трее (правый нижний угол):

* 🖧 **Кабель (Ethernet)** — обычно работает сразу после включения, ничего настраивать не нужно.
* 📶 **Wi-Fi** — кликните по значку ➔ выберите сеть школы ➔ введите пароль Wi-Fi. Поставьте галочку **«Подключаться автоматически»**, чтобы не вводить пароль каждый раз.

::: tip НЕТ ИНТЕРНЕТА — БЫСТРЫЙ ЧЕК-ЛИСТ
1. Значок сети в трее есть? Если с «!» или крестиком — перекликните подключение.
2. Другие компьютеры в кабинете работают? Если нет — проблема общая, сообщите администратору.
3. Ноутбук: не выключен ли Wi-Fi аппаратной кнопкой `Fn + F2/F12`?
4. Перезагрузитесь — банально, но решает половину бытовых проблем.
:::

## Какой браузер выбрать

В Astra Linux установлены **Chromium** (полный аналог Chrome) и **Firefox**. Работать можно в любом; для школьных сайтов (Дневник.ру, Госуслуги-образовательные сервисы) чаще рекомендуют Chromium.

| Задача | Лучше подойдёт |
| --- | --- |
| Школьные порталы, электронные журналы | Chromium |
| Привычки из Firefox, строгая приватность | Firefox |
| Показ сайта классу с проектора | любой, но заранее откройте нужные вкладки |

## Настройка браузера под учителя

### Закладки и панель «Избранное»

Добавьте одной кнопкой доступ к нужному: нажмите ⭐ в адресной строке или `Ctrl + D`. Рекомендуемый набор папок в закладках:

* **Уроки** — интерактивные доски, тесты (ЯКласс, Учи.ру, MyOralRead…).
* **Работа** — электронный журнал, дневник, почта.
* **Методичка** — ФИПИ, единая коллекция ЦОР, каталоги учебников.

### Профили

Если за компьютером работаете только вы — используйте отдельный профиль браузера и включите сохранение паролей: локальный профиль хранит закладки, пароли и настройки на компьютере. Облачную синхронизацию (аккаунт Google и т. п.) в школьной сети обычно использовать нельзя — уточните правила у администратора.

::: warning ЧУЖОЙ КОМПЬЮТЕР = РЕЖИМ ИНКОГНИТО
Открываете сайты с ученического или чужого компьютера? Используйте режим инкогнито: **`Ctrl + Shift + N`** (Chromium) / **`Ctrl + Shift + P`** (Firefox). После закрытия окна история, пароли и куки не сохранятся.
:::

### Полезные расширения для работы

Расширения ставятся только из официального магазина (Chrome Web Store / Add-ons Firefox):

* **uBlock Origin** — блокирует рекламу на образовательных видео.
* **PDF-просмотрщик** встроен в браузер — ссылки на методички открываются без скачивания.
* **Переводчик** (встроен в Chromium: правая кнопка по странице ➔ «Перевести»).

## Поиск материалов к уроку безопасно

1. Проверяйте источник: официальные порталы (ФИПИ, естествознание.ру, единая-коллекция.рф) надёжнее случайных сайтов из рекламы.
2. Скачивайте файлы только в папку **Загрузки** и открывайте через антивирус/после проверки.
3. Не открывайте ссылки из писем с просьбой «срочно оплатить» или «ваш аккаунт заблокирован» — это фишинг.

## 📚 Официально и для опытных

Коротко — что говорят документы «Астра Линукс» и где копать глубже, если вы уже работаете в системе уверенно:

* В Astra SE браузер по умолчанию — Яндекс.Браузер или Chromium из официального репозитория; оба внесены в реестр Минцифры. Состав «коробки» SE 1.8 опубликован на docs.astralinux.ru.
* Сетевой стек настраивается утилитой **NetworkManager** (`nmcli`, аплеты в трее); официальное описание — вики «Настройка сети в Astra Linux».
* Подлинность обновлений проверяется GPG-ключами репозитория (`/etc/apt/trusted.gpg.d/astra-*`); публичные ключи и зеркала перечислены в руководствах на docs.astralinux.ru.

::: tip Как пользоваться этими ссылками
Официальная вики **wiki.astralinux.ru** и портал документации **docs.astralinux.ru** доступны без регистрации; страницы с пометкой «Special Edition» описывают сертифицированную ФСТЭК редакцию, которая стоит в большинстве школ. Если раздел вики недоступен — скачайте официальное руководство в PDF с docs.astralinux.ru.
:::

## Практическое задание ✅

1. Подключитесь к школьному Wi-Fi и включите автоподключение.
2. Создайте в закладках папки «Уроки», «Работа», «Методичка» и добавьте по одному сайту в каждую.
3. Откройте любую страницу в режиме инкогнито и убедитесь, что история не сохраняется.
