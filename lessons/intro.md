# 🖥️ 1.1. Интерфейс Fly и Рабочий стол

**Цель урока:** научиться ориентироваться на рабочем столе Astra Linux, открывать программы и управлять окнами.

::: tip ИТОГО: 3–5 МИНУТ
Это самый первый урок курса. Читайте и сразу повторяйте каждое действие на своём компьютере.
:::

## Что такое оболочка Fly

Astra Linux использует графическую оболочку **Fly** (Fly 2) — она очень похожа на привычную Windows, поэтому переучиваться не придётся:

* **Панель задач** — внизу экрана, как в Windows.
* **Меню «Пуск»** — кнопка со звёздочкой в левом нижнем углу.
* **Рабочий стол** — свободная область с ярлыками.
* **Системный трей** — правый нижний угол: часы, сеть, звук, уведомления.

## Меню «Пуск»

1. Нажмите на кнопку **«Пуск»** (звёздочка в левом нижнем углу).
2. В строке поиска можно сразу начать печатать название программы — например, `текстовый` или `браузер`.
3. Разделы меню:
   * **Избранное** — часто используемые программы.
   * **Категории** — все программы по группам (Офис, Интернет, Мультимедиа).
   * **Недавние документы** — последние открытые файлы.
   * **Завершение работы** — «Сменить пользователя», «Выключить», «Перезагрузить».

::: warning НЕ ВЫКЛЮЧАЙТЕ КОМПЬЮТЕР КНОПКЕЙ НА КОРПУСЕ
Используйте только завершение работы через меню «Пуск». Принудительное выключение может повредить несохранённые файлы.
:::

## Рабочий стол и ярлыки

* Двойной клик по значку **«Домашняя папка»** открывает файловый менеджер.
* Чтобы создать ярлык своей папки на рабочем столе: откройте нужную папку, нажмите правой кнопкой мыши по ней ➔ **«Отправить» ➔ «Рабочий стол (создать ссылку)»**.
* Правой кнопкой мыши по пустому месту рабочего стола можно вызвать меню: создать папку, изменить фон, настроить разрешение экрана.

## Управление окнами

| Действие | Как сделать |
| --- | --- |
| Свернуть окно | Кнопка «—» в заголовке окна |
| Развернуть на весь экран | Кнопка «□» в заголовке окна |
| Закрыть окно | Крестик «×» |
| Переключить окно | `Alt + Tab` |
| Закрыть активное окно | `Alt + F4` |
| Показать рабочий стол | `Win + D` |

::: tip СОВЕТ ДЛЯ УРОКА
Если ученики смотрят на ваш экран через проектор, заранее разверните нужное окно на весь экран (`F11` в браузере работает так же).
:::

## Виртуальные рабочие столы

В Astra Linux можно несколько «рабочих столов» — как будто у вас несколько мониторов:

* Переключение: `Ctrl + Alt + ←` / `Ctrl + Alt + →`
* На одном столе держите браузер для урока, на другом — журнал и документы.

## Практическое задание ✅

1. Откройте через меню «Пуск» текстовый редактор и напишите любую фразу.
2. Разверните окно на весь экран и верните обратно.
3. Переключитесь между двумя открытыми окнами сочетанием `Alt + Tab`.
4. Выведите на рабочий стол ярлык своей домашней папки.
