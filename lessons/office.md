# 📝 2.1. Офис, шрифты PT Astra и .docx

**Цель урока:** научиться создавать школьные документы в LibreOffice и сохранять их так, чтобы они открывались на любом компьютере.

## Какой офис установлен

В Astra Linux по умолчанию работает бесплатный офисный пакет **LibreOffice** — полный аналог MS Office:

| Программа LibreOffice | Аналог в Windows | Для чего |
| --- | --- | --- |
| LibreOffice Writer | Microsoft Word | Конспекты, заявления, протоколы |
| LibreOffice Calc | Microsoft Excel | Журналы, таблицы, расчёты |
| LibreOffice Impress | PowerPoint | Презентации к урокам |

Открываются все эти программы через меню «Пуск» ➔ категория **«Офис»**.

## Шрифты PT Astra

Официальные документы в школе оформляются по ГОСТ с использованием шрифтов подлицензионной серии **PT** («Платформа Типографика»):

* **PT Sans** — заголовки, презентации (быстро читается с проектора).
* **PT Serif** — основной текст официальных документов (аналог Times New Roman).

В Astra Linux эти шрифты обычно предустановлены. Проверить и добавить свои шрифты можно через меню «Пуск» ➔ «Параметры» ➔ **«Шрифты»**, либо скопировать файлы `.ttf` в папку `~/.local/share/fonts`.

::: tip РАЗМЕРЫ ДЛЯ ПРОЕКТОРА
Для показа классу: заголовки — не меньше **32 pt**, основной текст — не меньше **24 pt**. Мелкий текст с задней парты не видно.
:::

## Золотое правило сохранения (.docx)

Документы LibreOffice по умолчанию сохраняются в своём формате `.odt`. Он отличный, но на компьютерах с Windows может не открыться.

Чтобы всегда получать совместимый `.docx`:

1. **Файл** ➔ **Сохранить как…** (`Ctrl + Shift + S`).
2. В поле **«Тип файла»** выберите **Word 2007–365 (.docx)**.
3. Нажмите «Сохранить».

Чтобы не выбирать формат каждый раз:

**Сервис** ➔ **Параметры** ➔ **Нагрузка/сохранение** ➔ **Общие** → в разделе «Сохранять в формате» для текстовых документов, таблиц и презентаций выберите **«Word 2007-365»**.

::: warning ЕСЛИ ДОКУМЕНТ НУЖНО ОТКРЫТЬ НА ЧУЖОМ КОМПЬЮТЕРЕ
Проверьте это заранее! После сохранения в `.docx` попросите администратора открыть файл в MS Word — сложные рамки, колонки и формулы иногда «съезжают».
:::

## Полезные мелочи для учителя

* **Автосохранение:** Сервис ➔ Параметры ➔ Открыть/Сохранить ➔ включите «Сохранять сведения о восстановлении каждые N минут».
* **Экспорт в PDF для печати:** Файл ➔ «Экспорт в PDF» — так документ гарантированно напечатается одинаково на любом принтере.
* **Шаблоны:** сохраните пустой файл с шапкой школы как `.ott` — и новые конспекты будут сразу в нужном оформлении.
* **Оформление по ГОСТ:** поля документа для школьных приказов и пояснительных записок — левое 3 см, правое 1–1,5 см, верхнее/нижнее 2 см; основной шрифт PT Serif 14 pt, межстрочный интервал 1,5. Сохраните такие настройки в шаблон и не выставляйте каждый раз вручную.
* **Нумерация страниц:** Вставка ➔ Номер ➔ Страница (начиная со второй титульной — Формат ➔ Абзац ➔ «Не нумеровать первую страницу»).
* **Оглавление для больших работ** (программы курса, методички): задайте стили «Заголовок 1/2», затем Вставка ➔ Оглавление и указатели — список обновляется одной кнопкой F9.

## Практическое задание ✅

1. Создайте в Writer документ «Конспект урока» с заголовком (PT Sans, 32 pt) и основным текстом (PT Serif, 14 pt).
2. Сохраните его в формате `.docx` в папку `Документы/Уроки`.
3. Экспортируйте копию в PDF.
4. Настройте LibreOffice на сохранение в `.docx` по умолчанию.
5. Сделайте шаблон служебной записки с полями по ГОСТ и сохраните как `.ott`.
