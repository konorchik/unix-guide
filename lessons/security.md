# 🛡️ 4.1. Безопасность и Помощь

**Цель урока:** выработать простые привычки, которые защитят ваши данные, и знать порядок действий при сбоях.

## Пароли и учётная запись

* Не оставляйте компьютер без пароля при входе — даже в своём кабинете.
* Блокировка экрана на время перемены: **`Win + L`**.
* Пароль администратора (нужен для установки программ и принтеров) сообщайте только системному администратору школы — учителю-предметнику он почти никогда не нужен.

::: danger НИКОГДА
Не передавайте свой логин и пароль ученикам и не оставляйте записки с паролем на мониторе. Это нарушение политики обработки персональных данных (ФЗ-152), если в системе есть журналы и данные учеников.
:::

## Обновления системы

Раз в неделю устанавливайте обновления: меню «Пуск» ➔ «Системные» ➔ **«Обновление системы»**. Обновления закрывают дыры, через которые вирусы и вредоносные программы попадают в систему.

## Простые правила «гигиены»

1. Скачивайте программы **только** из официального менеджера приложений или репозитория (не «с сайтов из поиска»).
2. Проверяйте флешки, принесённые учениками, антивирусом перед открытием.
3. Держите копии важных документов в двух местах: домашняя папка + облако/второй носитель (как настроить копии — урок [4.3. Резервные копии](/lessons/backup)).

## Флешки учеников: безопасная проверка

Флешка «из портфеля пятиклассника» — главный переносчик проблем в школьных ПК. Порядок действий:

1. Вставьте флешку ➔ **не открывайте** файлы двойным кликом.
2. Запустите проверку: если в школе настроен антивирус (Dr.Web, KaspersITS для Linux) — он предложит сканирование автоматически; при его отсутствии хотя бы осмотрите содержимое через файловый менеджер, отключив показ скрытых файлов по умолчанию.
3. Тревожные признаки: файл `autorun.inf`, документы с двумя расширениями (`Доклад.docx.exe`, `Фото.jpg.scr`), архивы-«пароли». Такой носитель лучше не использовать до проверки администратором.
4. Открывайте презентации **копированием на компьютер**, а не с флешки — и быстрее, и безопаснее (см. чек-лист в [Шпаргалках](/lessons/shortcuts)).

::: warning НЕ ОТКЛЮЧАЙТЕ ЗАЩИТУ Astra Linux SE
В сертифицированной версии включены контроль целостности и мандатный доступ. Система может блокировать запуск программ с флешек или требовать подтверждения запуска — это не поломка, а защита. Не пытайтесь её «отключить»: обратитесь к администратору.
:::

## Программа зависла — что делать

**Шаг 1.** Подождите 30–60 секунд — возможно, программа просто обрабатывает большой файл.

**Шаг 2.** Закройте программу корректно: `Alt + F4`.

**Шаг 3.** Запустите монитор ресурсов: `Ctrl + Alt + Esc` (или меню «Пуск» ➔ «Системный монитор»). Найдите программу в списке процессов ➔ правая кнопка ➔ «Завершить процесс».

**Шаг 4.** Крайний вариант — завершение сеанса: `Ctrl + Alt + Backspace` (если включено) или перезагрузка через меню «Пуск» ➔ «Завершение работы».

::: tip СОХРАНЯЙТЕ ЧАСТО
Привычка `Ctrl + S` каждые несколько минут спасает при любом сбое. В LibreOffice включите автосохранение (Сервис ➔ Параметры ➔ Открыть/Сохранить).
:::

## Система не загружается / «чёрный экран»

Не пытайтесь «починить» систему командами из интернета — это задача администратора. Запишите:

* после каких действий появилась проблема;
* текст ошибки (сфотографируйте экран);
* модель компьютера.

С этой информацией обратитесь к системному администратору школы — починка займёт минуты, а не часы.

## Экстренная памятка (распечатайте и положите у компьютера) ✍️

| Симптом | Первое действие |
| --- | --- |
| Программа не отвечает | `Alt + F4`, затем «Системный монитор» (`Ctrl + Alt + Esc`) |
| Залип курсор / тормоза | Перезагрузите компьютер штатно через «Пуск» |
| Флешка не открывается | Другой USB-порт, безопасно извлечь и вставить заново |
| Нет звука | Трей ➔ Настройки звука ➔ правильное устройство вывода |
| Проектор не показывает | `Super + P` / Параметры ➔ Дисплей ➔ «Дублировать» |
| Забыли пароль входа | Обратитесь к администратору школы |

::: success ВЫ ПРОШЛИ КУРС! 🎉
Компьютер больше не пугает. Возвращайтесь к урокам в любой момент — и распечатайте шпаргалки: [Шпаргалки и горячие клавиши](/lessons/shortcuts). Полезные дополнения: [4.2. Терминал и установка программ](/lessons/terminal), [4.3. Резервные копии](/lessons/backup) и [FAQ](/lessons/faq).
:::

## 📚 Официально и для опытных

Коротко — что говорят документы «Астра Линукс» и где копать глубже, если вы уже работаете в системе уверенно:

* Astra Linux SE сертифицирована **ФСТЭК России** (СЗИ от НСД, соответствие приказам ФСТЭК №21 и №17) — формуляры и сертификаты публикует astralinux.ru в разделе «Сертификация».
* Встроенные СЗИ: мандатный контроль доступа, межсетевой экран, режим повышенной защиты («паранойя», утилита `paranoia`) — штатные механизмы описаны в руководстве администратора SE на docs.astralinux.ru.
* Обновления безопасности распространяются через официальные репозитории `apt.astralinux.ru`; бюллетени публикуются в разделе «Безопасность» сайта Astra (astralinux.ru/security).

::: tip Как пользоваться этими ссылками
Официальная вики **wiki.astralinux.ru** и портал документации **docs.astralinux.ru** доступны без регистрации; страницы с пометкой «Special Edition» описывают сертифицированную ФСТЭК редакцию, которая стоит в большинстве школ. Если раздел вики недоступен — скачайте официальное руководство в PDF с docs.astralinux.ru.
:::
