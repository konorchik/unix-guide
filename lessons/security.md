# 🛡️ 4.1. Безопасность и Помощь

**Цель урока:** выработать простые привычки, которые защитят ваши данные, и знать порядок действий при сбоях.

## Пароли и учётная запись

* Не оставляйте компьютер без пароля при входе — даже в своём кабинете.
* Блокировка экрана на время перемены: **`Win + L`**.
* Пароль администратора (нужен для установки программ и принтеров) сообщайте только системному администратору школы — учителю-предметнику он почти никогда не нужен.

::: danger НИКОГДА
Не передавайте свой логин и пароль ученикам и не оставляйте записки с паролем на мониторе. Это нарушение политики обработки персональных данных (ФЗ-152), если в системе есть журналы и данные учеников.
:::

## Обновления системы

Раз в неделю устанавливайте обновления: меню «Пуск» ➔ «Системные» ➔ **«Обновление системы»**. Обновления закрывают дыры, через которые вирусы и вредоносные программы попадают в систему.

## Простые правила «гигиены»

1. Скачивайте программы **только** из официального менеджера приложений или репозитория (не «с сайтов из поиска»).
2. Проверяйте флешки, принесённые учениками, антивирусом перед открытием.
3. Держите копии важных документов в двух местах: домашняя папка + облако/второй носитель.

## Программа зависла — что делать

**Шаг 1.** Подождите 30–60 секунд — возможно, программа просто обрабатывает большой файл.

**Шаг 2.** Закройте программу корректно: `Alt + F4`.

**Шаг 3.** Запустите монитор ресурсов: `Ctrl + Alt + Esc` (или меню «Пуск» ➔ «Системный монитор»). Найдите программу в списке процессов ➔ правая кнопка ➔ «Завершить процесс».

**Шаг 4.** Крайний вариант — завершение сеанса: `Ctrl + Alt + Backspace` (если включено) или перезагрузка через меню «Пуск» ➔ «Завершение работы».

::: tip СОХРАНЯЙТЕ ЧАСТО
Привычка `Ctrl + S` каждые несколько минут спасает при любом сбое. В LibreOffice включите автосохранение (Сервис ➔ Параметры ➔ Открыть/Сохранить).
:::

## Система не загружается / «чёрный экран»

Не пытайтесь «починить» систему командами из интернета — это задача администратора. Запишите:

* после каких действий появилась проблема;
* текст ошибки (сфотографируйте экран);
* модель компьютера.

С этой информацией обратитесь к системному администратору школы — починка займёт минуты, а не часы.

## Экстренная памятка (распечатайте и положите у компьютера) ✍️

| Симптом | Первое действие |
| --- | --- |
| Программа не отвечает | `Alt + F4`, затем «Системный монитор» (`Ctrl + Alt + Esc`) |
| Залип курсор / тормоза | Перезагрузите компьютер штатно через «Пуск» |
| Флешка не открывается | Другой USB-порт, безопасно извлечь и вставить заново |
| Нет звука | Трей ➔ Настройки звука ➔ правильное устройство вывода |
| Проектор не показывает | `Super + P` / Параметры ➔ Дисплей ➔ «Дублировать» |
| Забыли пароль входа | Обратитесь к администратору школы |
