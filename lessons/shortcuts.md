# 📄 Шпаргалки и горячие клавиши

::: tip КАК РАСПЕЧАТАТЬ
Откройте эту страницу в браузере и нажмите `Ctrl + P`. Все таблицы разобьются на удобные памятки.
:::

## ⌨️ Горячие клавиши учителя

| Сочетание | Что делает |
| --- | --- |
| `Win + L` | Заблокировать экран (перемена!) |
| `Alt + Tab` | Переключить окно |
| `Alt + F4` | Закрыть программу |
| `Ctrl + C` / `Ctrl + X` / `Ctrl + V` | Копировать / вырезать / вставить |
| `Ctrl + Z` | Отменить последнее действие |
| `Ctrl + S` | Сохранить документ |
| `Ctrl + P` | Печать |
| `Ctrl + Shift + S` | Сохранить как… (выбор формата .docx) |
| `F2` | Переименовать файл |
| `Delete` | Удалить файл в корзину |
| `Ctrl + Alt + Esc` | Системный монитор (если программа зависла) |
| `Super + P` | Режимы второго экрана / проектора |
| `Ctrl + Alt + ←/→` | Виртуальные рабочие столы |

## 💾 Чек-лист работы с флешкой

1. Вставьте флешку ➔ дождитесь уведомления.
2. Откройте её в разделе **«Устройства»** файлового менеджера.
3. Скопируйте нужные файлы **на компьютер** (не открывайте презентацию прямо с флешки!).
4. По завершении: правая кнопка по флешке ➔ **«Безопасно извлечь»**.
5. Вынимайте накопитель только после разрешения системы.

## 🆘 Экстренная памятка

| Симптом | Первое действие |
| --- | --- |
| Программа не отвечает | Подождать 30 сек ➔ `Alt + F4` ➔ системный монитор |
| Нет изображения на проекторе | `Super + P` ➔ Параметры ➔ Дисплей ➔ «Дублировать» |
| Нет звука | Трей ➔ Настройки звука ➔ выбрать устройство вывода |
| Принтер молчит | Проверить очередь печати и статус «Готов» |
| Компьютер тормозит | Перезагрузка штатно через «Пуск» |
| Не помните пароль | Обратиться к администратору школы |
