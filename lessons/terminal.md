# ⌨️ 4.2. Терминал и установка программ

**Цель урока:** перестать бояться «чёрного окна» терминала, правильно ставить программы и знать пять команд, которые экономят время.

## Как в Astra Linux ставят программы

Забудьте про скачивание `.exe` с сайтов. В Linux программы берутся из **официального репозитория** — это как проверенный магазин:

1. **Менеджер приложений** («Пуск» ➔ «Менеджер приложений» / Fly-DRP): находите программу по имени ➔ «Установить» ➔ пароль администратора.
2. **Терминал** — то же самое одной командой (см. ниже). Подходит, когда знаете точное имя пакета.

::: danger ПАРОЛЬ АДМИНИСТРАТОРА
Установка программ требует прав администратора. Если у вас их нет — установкой занимается системный администратор школы. Не заведите себе «админку на всякий случай»: это нарушение требований ИБ образовательной организации.
:::

## Что нужно учителю: проверенный список

| Задача | Программа | Имя пакета для установки |
| --- | --- | --- |
| Архивы RAR/7z | Архиватор (поддержка в fly-fm) | `p7zip-full unrar` |
| Просмотр PDF с пометками | Okular / Xournal++ | `okular`, `xournalpp` |
| Запись звука | Audacity | `audacity` |
| Видеоплеер для уроков | VLC | `vlc` |
| Интерактивная доска | Open-Sankoré / Xournal++ | `xournalpp` |
| Таймер/секундомер для класса | KTimeTracker / Gnome stopwatch | `gnome-shell-extension-*` (уточнить у администратора) |
| Рисование схем | Draw.io Desktop или Inkscape | `inkscape` |

VLC открывает любые форматы видео с флешки — держите его установленным в кабинете.

## Терминал: открываем и не боимся

Запуск: меню «Пуск» ➔ **«Терминал»** (fly-term), или `Ctrl + Alt + T`.

Текст, который вы видите — приглашение: `ivanov@school05:~$` — пользователь@компьютер:текущая_папка$. `~` значит домашняя папка.

### Пять полезных команд учителя

```bash
cd Документы/Уроки      # перейти в папку (аналог двойного клика)
ls                      # показать содержимое папки
pwd                     # где я сейчас?
xdg-open konспект.docx  # открыть файл программой по умолчанию
exit                    # закрыть терминал
```

Ещё три на каждый день:

```bash
df -h                   # сколько свободного места на диске (когда ругается «мало места»)
du -sh ~/Загрузки       # сколько занимают скачанные файлы
top                     # что тормозит компьютер (выход — q); аналог «Системного монитора»
```

### Установка и обновление программ через терминал

```bash
sudo apt update              # обновить список доступных программ
sudo apt install vlc         # установить VLC
sudo apt remove vlc          # удалить VLC
```

`sudo` = «выполнить с правами администратора»; система спросит **ваш пароль администратора** (при вводе символы не отображаются — это нормально, просто печатайте и `Enter`).

::: warning КОПИРУЙТЕ КОМАНДЫ ТОЧНО
Никогда не выполняйте команды, скопированные из сомнительных инструкций «почини сам», особенно со словами `rm -rf`, `dd`, `chmod 777`. Одна лишняя буква может стереть данные. Согласовывайте такие действия с администратором.
:::

## Если программа не запускается

1. Запустите её из терминала по имени (`vlc`) — в окне появится текст ошибки, его и показывайте администратору.
2. Проверьте обновления: «Системное обновление» из урока [4.1](/lessons/security).
3. Удалите и установите программу заново через менеджера приложений.

## 📚 Официально и для опытных

Коротко — что говорят документы «Астра Линукс» и где копать глубже, если вы уже работаете в системе уверенно:

* Состав репозиториев SE (stable / updates) и адреса зеркал опубликованы в официальном руководстве «Обновление системы» на docs.astralinux.ru.
* Поиск имени пакета: `apt search <слово>` или `apt-file search <файл>` (пакет `apt-file`); полный каталог ПО «коробки» SE — в списке пакетов к дистрибутиву.
* Полезно знать: `dpkg -l | less` (установленные пакеты), `apt show vlc` (описание пакета), `systemctl status <служба>` (состояние служб); базовая документация Debian — debian.org/doc.

::: tip Как пользоваться этими ссылками
Официальная вики **wiki.astralinux.ru** и портал документации **docs.astralinux.ru** доступны без регистрации; страницы с пометкой «Special Edition» описывают сертифицированную ФСТЭК редакцию, которая стоит в большинстве школ. Если раздел вики недоступен — скачайте официальное руководство в PDF с docs.astralinux.ru.
:::

## Практическое задание ✅

1. Откройте терминал и командами `cd`, `ls`, `pwd` найдите свой конспект в `Документы/Уроки`.
2. Откройте его командой `xdg-open имя_файла.docx`.
3. Выполните `df -h` и посмотрите, сколько свободно на системном диске.
4. Попросите администратора вместе установить VLC через менеджер приложений.
