# 🔄 1.0. Переезд с Windows: что изменилось

**Цель урока:** за 5 минут снять главный страх — «я ничего не найду». После прочтения вы поймёте, что 90% навыков из Windows работают здесь так же.

::: tip ГЛАВНАЯ МЫСЛЬ
Astra Linux визуально почти повторяет Windows: панель внизу, «Пуск» слева, трей справа. Отличия — в мелочах, и они все перечислены ниже.
:::

## Что осталось как в Windows

| Действие | В Windows | В Astra Linux |
| --- | --- | --- |
| Закрыть программу | крестик / `Alt + F4` | так же |
| Свернуть все окна | `Win + D` | `Win + D` или значок «Свернуть все» в правом углу панели |
| Переключить окно | `Alt + Tab` | так же |
| Копировать/вставить | `Ctrl + C/V` | так же |
| Поиск программ | «Пуск» ➔ печатаете имя | «Пуск» (звёздочка) ➔ печатаете имя |
| Проводник | жёлтая папка | синий/серый значок папки — файловый менеджер «Файлы» |

## Что устроено иначе

### 1. Буквы дисков C: и D: — их нет

В Linux один корень `/`, а ваши файлы живут в **домашней папке**:

```text
/home/ivanov/            ← ваша домашняя папка (аналог C:\Users\ivanov)
├── Документы/           ← «Мои документы»
├── Рабочий стол/        ← рабочий стол
├── Загрузки/            ← папка Downloads
└── Изображения/         ← картинки
```

* Флешки подключаются как папки в разделе **«Устройства»** файлового менеджера — никаких букв `E:`/`F:`.
* Программы ставятся не скачиванием `.exe` с сайтов, а через **менеджер приложений** (как магазин программ). Об этом — урок [4.2. Терминал и установка программ](/lessons/terminal).

### 2. Регистр букв важен

`Файл.docx` и `файл.docx` — для системы это **два разных файла**. При переносе документов с Windows иногда возникают ссылки «файл не найден» именно из-за этого. Совет: называйте файлы строчными буквами без пробелов (`konспект-5k.docx`).

### 3. Права администратора запрашиваются паролем

При установке программ, печати на общем принтере или изменении системных настроек система попросит **пароль администратора**. Это нормально и является защитой от вирусов. Учителю-предметнику обычно хватает работы без него — настройками техники занимается администратор школы.

### 4. Корзина и «Очистка диска»

Удалённые файлы попадают в **Корзину** на рабочем столе (как в Windows). Освободить место: правая кнопка по корзине ➔ «Очистить корзину».

### 5. Смена раскладки клавиатуры

По умолчанию в Astra Linux переключение языков — `Super + Пробел` (клавиша с флажком), но часто настраивают привычные `Alt + Shift` или `Ctrl + Shift`. Проверить: «Пуск» ➔ «Параметры» ➔ «Клавиатура» ➔ вкладка «Раскладка».

## Чего не хватает и чем заменить

| Привычная программа | Замена в Astra Linux |
| --- | --- |
| Microsoft Word / Excel / PowerPoint | **LibreOffice** Writer / Calc / Impress (бесплатно, предустановлен) |
| Блокнот | Текстовый редактор Fly (Flywrite) |
| Проводник | Файловый менеджер fly-fm («Файлы») |
| Chrome | **Chromium** / Яндекс.Браузер / Mozilla Firefox |
| Skype | ВКонтакте, Rocket.Chat, Zoom (веб-версия) |
| 7-Zip | Архиватор Fly (правая кнопка ➔ «Сесть в архив…») |
| MS Office-макроформы журнала | Уточните у администрора школьную веб-систему (Дневник.ру, Электронный журнал региона) |

::: warning НЕ СКАЧИВАЙТЕ «EXE-ШНИКИ»
Файлы `.exe` здесь не запускаются, а программы «с интернета в взломанном виде» — прямой путь к вирусу. Правило одно: только менеджер приложений или официальные сайты производителей Linux-версий.
:::

## Первые пять действий после установки (чек-лист)

1. Смените пароль при первом входе и запомните его (не на стикере!).
2. Добавьте свои предметы в «Избранное» меню «Пуск»: браузер, LibreOffice, «Файлы».
3. Настройте часы и часовой пояс (трей ➔ дата/время) — от этого зависят обновления.
4. Создайте структуру папок `Документы/Уроки/<предмет>` — см. урок [1.2. Работа с файлами](/lessons/files).
5. Распечатайте шпаргалку горячих клавиш: [Шпаргалки](/lessons/shortcuts).

## Практическое задание ✅

1. Найдите свою домашнюю папку и покажите её содержимое в файловом менеджере.
2. Проверьте, какой комбинацией у вас переключается раскладка клавиатуры.
3. Откройте «Пуск» ➔ наберите `libre` и запустите Writer.
